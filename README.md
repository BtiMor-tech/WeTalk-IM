- 企业内部沟通与组织架构消息
- 与智能客服同栈的私有化部署
- 需要源码交付、可二次开发的团队
- 渠道/代理按官网政策合作落地

## 能力概览

公开说明级能力边界（合同包可含扩展项，以签约清单为准）：

- **消息**：单聊、群聊、已读回执、组织架构通讯录
- **协同**：文件/图片传输、会话检索（以交付版本为准）
- **管理**：管理后台、角色与权限、审计导出（以交付版本为准）
- **部署**：Linux / 内网；推荐容器化；依赖数据库、对象存储（或本地盘）、反向代理与 TLS
- **联调**：可与比特摩尔 AI 智能客服同栈部署（接口与版本以合同包为准）

详细条目见 [`docs/功能清单.md`](docs/功能清单.md)。
