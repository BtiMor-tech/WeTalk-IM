# 交付与验收

## 目标

把「交什么、怎么验、何时放行」写成可签字维度。

## 交付物（按版本）

| 版本 | 典型交付物 |
|------|------------|
| 非开源版 ¥15,888 | 可运行包、部署说明、基础使用培训（以合同为准） |
| 开源版 ¥23,888 | 上述 + 可二次开发源码（范围以《源码授权协议》为准） |
| 白标 / 含部署 | 详询；含实施与验收节奏时写入合同附件 |

## 验收维度（建议）

| 层级 | 抽检点 | 通过标准（示例） |
|------|--------|------------------|
| L1 | 同网段单聊/群聊 | 消息可达、已读一致 |
| L2 | 组织架构与登录 | 成员可见、权限符合角色表 |
| L3 | 文件/图片传输 | 校验完整；大小策略生效 |
| L4 | 管理与审计 | 后台可操作；导出字段符合清单 |
| L5 | 备份恢复抽样 | 消息/文件抽样可恢复 |

完整测试单由实施包提供；上线放行需双方签字确认未关闭的 P0 缺陷清单。

## 资源需求

- 客户侧：一台验收环境、测试账号、网络策略窗口  
- 我方：实施工程师与验收清单（合同约定人天）

## 风险控制

- 未完成备份恢复抽样不建议切生产  
- 性能指标以实测与合同为准  
- 变更与增购走补充协议
