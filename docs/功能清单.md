# 功能清单（公开说明）

说明级清单，便于采购对齐。签约以合同附件功能表为准；下列「标配」指常见交付包默认包含项。

## 消息与会话

| 能力 | 说明 | 常见交付 |
|------|------|----------|
| 单聊 / 群聊 | 文本消息、基础表情 | 标配 |
| 已读回执 | 会话侧已读状态 | 标配 |
| 组织架构通讯录 | 部门 / 成员树 | 标配 |
| 文件 / 图片 | 会话内传输；大小上限以实施方案为准 | 标配 |
| 会话检索 | 历史消息检索能力随版本 | 按版本 |

## 管理与安全

| 能力 | 说明 | 常见交付 |
|------|------|----------|
| 管理后台 | 组织、成员、基础策略 | 标配 |
| 角色权限 | 管理端角色划分 | 标配 |
| 审计导出 | 关键操作 / 会话元数据导出（范围以合同为准） | 按版本 |
| 备份恢复 | 库与文件备份策略见交付文档 | 实施方案 |

## 与 AI 智能客服同栈

| 能力 | 说明 |
|------|------|
| 同栈部署 | 可作为「AI 智能客服 + 企业 IM」一体化私有化方案的一部分 |
| 转接 / 协同 | 具体接口与版本以合同技术附件为准 |

## 明确边界

- 本公开仓 **不提供** 全量源码与可运行安装包下载；源码 / 安装包按合同交付。
- 性能数字（并发、QPS）以实测与合同 SLA 为准。
- 白标视觉与定制项：**详询**。
