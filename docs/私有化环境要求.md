# 私有化环境要求

公开说明级清单。最终规格以实施方案与合同为准。

## 目标

让采购与 IT 在签约前对齐机房、网络与依赖边界。

## 落地路径

1. 确认部署位置：客户云 / 自建机房 / 专网  
2. 准备 Linux 主机或 Kubernetes（以合同包为准）  
3. 准备数据库与对象存储（或足够本地盘）  
4. 准备域名与 TLS 证书（若对外暴露管理端/客户端）  
5. 按交付包完成安装与联调，走验收清单

## 资源需求（需结合历史交付数据校准）

| 档位 | 说明 |
|------|------|
| 小型试点 | 单机或小规格云主机可起步；具体 CPU/内存/磁盘以实施方案为准 |
| 生产 | 按并发在线与消息、文件峰值扩容；公开仓不承诺具体 QPS |

## 依赖清单（典型）

- Linux 服务器或容器运行时  
- 关系型数据库  
- 对象存储或本地文件盘  
- 反向代理与 TLS  
- 出网策略：按客户安全要求；纯内网方案在合同中单独约定

## 风险控制

- 密钥、许可证、客户配置 **不** 进入本公开仓  
- 备份与恢复演练写入交付验收，上线前至少完成一次抽样恢复  
- 规格变更走变更单，避免口头扩容承诺
