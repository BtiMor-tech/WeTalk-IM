# 部署概览

## 目标

说明比信（WeTalk）IM 私有化交付的典型部署边界，便于采购与实施对齐。

## 落地路径（概要）

1. **环境**：Linux 服务器 / 内网；推荐容器化部署（具体镜像与编排以合同包为准）。  
2. **依赖**：数据库、对象存储（或本地盘）、反向代理与 TLS。  
3. **交付物**：按版本提供可运行包或源码；开源版含可二次开发源码。  
4. **验收**：按合同清单做功能与性能抽检；演示环境可预约。

## 资源需求（需结合历史交付数据校准）

- 小型试点：单机或小规格云主机即可起步（具体规格以实施方案为准）。  
- 生产：按并发在线与消息峰值扩容；具体容量规划写入实施方案。

## 风险控制

- 公开仓不存放客户配置、密钥、许可证文件。  
- 本仓库仅覆盖国内企业 IM / 智能客服私有化说明，不涉及境外业务叙事。  
- 挂牌价以官网与合同为准；白标与部署实施详询。
